# Printable Assets — القطع المطبوعة

مساحة مخصّصة لملفات الطباعة ثلاثية الأبعاد وإرشاداتها.
**لا توجد ملفات 3D هنا بعد** — هذا القسم مُجهَّز ومواصفاته محدّدة.

```
printable-assets/
├── README.md          ← هذا الملف
├── file/              ← الملف: العنصر الأساسي
├── dice/              ← نرد سداسي (اختياري)
├── dice-cups/         ← أكواب النرد (اختياري)
└── host-stand/        ← حامل الجهاز الرئيسي (اختياري)
```

---

## 1. الملف — العنصر الأساسي (إلزامي)

القطعة الوحيدة التي لا تعمل اللعبة بدونها. توضع في منتصف الطاولة ويأخذها
مُخفي الملف في الظلام.

المرجع البصري: [`src/ui/components/FileProp.tsx`](../src/ui/components/FileProp.tsx)
— ملف بغلاف كهرماني بزاوية علوية بارزة وأوراق بيضاء بداخله.

### المتطلبات الوظيفية

| المتطلب | السبب |
|---|---|
| سهل الرؤية من كل المقاعد | يجب أن يلاحظ الجميع اختفاءه فورًا |
| **صامت عند الرفع** | أهم متطلب على الإطلاق — الصوت يكشف المُخفي |
| يُمسك بيد واحدة | تُرفع القطعة في الظلام وبعين واحدة مفتوحة |
| بلا زوايا حادة | تُلتقط بلا نظر |
| ثابت لا يتدحرج | لا يتحرك بلمسة عابرة فيُربك الجولة |

### المواصفات المقترحة

| البند | القيمة |
|---|---|
| الأبعاد | ‎90 × 70 × 18 مم تقريبًا |
| الوزن | 60–110 غ — ثقيل بما يكفي ليثبت، خفيف بما يكفي ليُرفع بهدوء |
| المادة | PLA أو PETG |
| الحشو | 15–25% |
| الطبقة | 0.2 مم |
| الدعامات | غير مطلوبة إن طُبع مسطحًا |
| القاعدة | لبادة لباد أو TPU ناعمة — **تلغي صوت الرفع والوضع** |
| نصف قطر الحواف | ≥ 3 مم |

### الألوان

اللون الأساسي كهرماني `oklch(0.80 0.145 78)` ≈ `#F0B542`.
يمكن إنتاج ألوان بديلة (أزرق، نعناعي، مرجاني) للمجموعات المتعددة —
اللون لا يؤثر على القواعد إطلاقًا.

## 2. النرد السداسي (اختياري)

للنمط الهجين فقط. النمط الافتراضي رقمي ولا يحتاجه.

| البند | القيمة |
|---|---|
| المقاس | 16 مم |
| الحواف | مستديرة ≥ 1.5 مم |
| النقاط | غائرة 1 مم لتُقرأ باللمس في الإضاءة الخافتة |
| العدد | واحد لكل لاعب (اثنان في وضع الأربعة لاعبين) |

## 3. أكواب النرد (اختياري)

تُخفي نتيجة النرد عن بقية اللاعبين أثناء الرمي.

| البند | القيمة |
|---|---|
| القطر الداخلي | 45 مم |
| الارتفاع | 55 مم |
| الجدار | 2 مم |
| الداخل | نسيج خشن يخفّف صوت الرمي |
| القاعدة | لبادة لباد |
| العدد | واحد لكل لاعب |

## 4. حامل الجهاز الرئيسي (اختياري)

يرفع جهاز المضيف في منتصف الطاولة ليُرى من كل المقاعد — يخدم «وضع الطاولة».

| البند | القيمة |
|---|---|
| الزاوية | 60–70° من المستوى الأفقي |
| الارتفاع | 110–140 مم |
| التوافق | جوال 6"–7" وتابلت حتى 11" |
| فتحة الشحن | مطلوبة — الجلسة تستهلك بطارية وشاشة الجهاز تبقى مضاءة |
| القاعدة | ثقيلة أو قابلة للتعبئة، مع لبادة |

## عند إضافة ملفات

1. ضع `.stl` و `.3mf` داخل المجلد المناسب.
2. أضف `PRINT_SETTINGS.md` بجوارها (الشريحة، المادة، الحشو، الدعامات، زمن الطباعة).
3. أضف صورة للقطعة المطبوعة فعلًا لا للنموذج فقط.
4. حدّث [`docs/ASSET_LIST.md`](../docs/ASSET_LIST.md).

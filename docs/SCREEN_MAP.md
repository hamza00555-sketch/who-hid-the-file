# خريطة الشاشات

كل مرحلة لها شاشتان مختلفتان تمامًا: واحدة على الجهاز الرئيسي وواحدة على جهاز اللاعب.
القاعدة الحاكمة: **الجهاز الرئيسي يعرض الحالة العامة، وجهاز اللاعب يعرض سر صاحبه فقط.**

| المرحلة | الجهاز الرئيسي | جهاز اللاعب | من ينقل للمرحلة التالية |
|---|---|---|---|
| `home` | مشهد افتتاحي + إنشاء جلسة + انضمام برمز | — | المستخدم |
| `join` | — | اسم + اختيار شخصية + «ادخل الجلسة» | اللاعب |
| `lobby` | رمز + QR + رابط + حلقة الطاولة + شارات الجاهزية + شريط البدء | «أنا جاهز» + رقم مقعده | المضيف |
| `seating-order` | تبويب داخل الردهة: سحب وإفلات + أزرار نقل | — | المضيف |
| `settings` | تبويب داخل الردهة: نمط النرد، المصطلح، المدد، الصوت | — | المضيف |
| `role-distribution` | «انظروا إلى أجهزتكم» + عدّاد التأكيدات | غطاء «سرّي» → الدور → «فهمت دوري» | تلقائي عند اكتمال `roleAck` |
| `dice-roll` | نرد متحرك + تعليمات النمط + عدّاد | رمي النرد أو إدخال الرقم → الموعد → «عرفت موعدي» | تلقائي عند اكتمال `diceAck` |
| `ready-check` | قائمة تحقق + «ابدأ الليل» | «ضع جهازك على الطاولة» | المضيف |
| `night-intro` | «بدأ الليل» + صوت | شاشة سوداء | مؤقت المضيف |
| `night-phase-1..6` | اسم المرحلة + عدّاد دائري + مقياس تقدّم + Caption | شاشة سوداء + اهتزاز عند الموعد | مؤقت المضيف |
| `secret-actions` | مشهد الملف المفقود + عدّاد الإجراءات | شاشة شخصية: فحص جار / متعاون / اختيار / «لا معلومة» | تلقائي عند اكتمال `secretAck` |
| `discussion` | حلقة الطاولة + مؤقت + إيقاف/استكمال | «ابدؤوا النقاش» — الجهاز يتنحّى | المضيف |
| `voting` | «صوّت X من Y» بلا أي تلميح | قائمة اللاعبين (بلا النفس) → قفل | تلقائي عند اكتمال الأصوات |
| `reveal` | ٣ ٢ ١ ← المكشوفون + أدوارهم + الفائز | «انظروا للجهاز الرئيسي» | مؤقت المضيف |
| `results` | جدول كامل + جولة جديدة + الرئيسية | فزت / خسرت + من كان المُخفي | المضيف |
| `paused` | «الجولة متوقفة» + استكمال | «انتظر إشارة المضيف» | المضيف |

## شاشات خدمية

| المسار | الغرض |
|---|---|
| `#/roster` | ورقة الشخصيات: 10 شخصيات × 9 حالات + العناصر. أداة مراجعة بصرية، ليست جزءًا من اللعب. |

## قواعد ثابتة عبر كل الشاشات

**الجهاز الرئيسي**
- لا يعرض دورًا ولا نردًا ولا موعدًا قبل شاشة النتائج.
- لا يخفت في الليل إطلاقًا — يجب أن يُقرأ من الطرف الآخر للطاولة.
- Caption متزامن أسفل الشاشة مع كل جملة منطوقة + زر إعادة.

**جهاز اللاعب**
- صامت تمامًا. الاهتزاز والتنبيهات الصامتة فقط.
- زر رئيسي واحد واضح في كل شاشة.
- كل سر خلف «غطاء» يتطلب لمسة واعية — لا يُكشف تلقائيًا بعد إعادة الاتصال.
- في الليل: شاشة شبه مطفأة، `pointer-events: none`، بلا نص مقروء من بعيد.
- شاشات المرحلة السرية كلها بنفس الشكل والزر — حتى «لا معلومة» — فلا يكشف الانتظار أحدًا.

**الرجوع والخروج**

زر الرجوع موجود حيث تكون المغادرة آمنة فقط، وفي الحافة البادئة (يمين الشاشة)
بالموضع نفسه على كل جهاز:

| الشاشة | الزر | السلوك |
|---|---|---|
| `#/roster` | «الرئيسية» | يعود مباشرة |
| `#/play/CODE` قبل الانضمام | «خروج» | يعود مباشرة — لا شيء يُكتب بعد |
| ردهة اللاعب | «خروج» | `leaveRoom` + نسيان الجلسة المحفوظة + الرئيسية |
| نتائج اللاعب | «خروج» | نفس السابق — الجولة انتهت |
| ردهة المضيف | «خروج» ← «أغلق الجلسة» | خطوة تأكيد: الرمز يخصّ بقية اللاعبين |
| نتائج المضيف | «الرئيسية» | زر أساسي داخل الشاشة، لا في الشريط |

لا يوجد رجوع في `role-distribution` و`dice-roll` و`ready-check` والليل
و`secret-actions` و`discussion` و`voting` و`reveal`: الشاشة تتبع `meta/phase`،
والخروج منها يكسر الجولة على بقية الطاولة.
